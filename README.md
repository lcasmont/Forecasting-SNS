# Forecasting-SNS

Forecasting Patient Demand for Long-Term Care in the Portuguese SNS

Developed SARIMA time-series models in R to forecast monthly patient referrals to Portugal's National Integrated Continuous Care Network (RNCCI). The project includes exploratory time-series analysis, STL decomposition, stationarity testing, ACF/PACF analysis, model selection and residual diagnostics, followed by out-of-sample validation using MAE, RMSE, and MAPE. Forecasts were translated into practical recommendations for hospital bed capacity planning.
